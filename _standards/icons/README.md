# Значки SeedWave — стандарт v2 (принят Игорем 17.11.2026)

Эталон — аватар WhatsApp-канала «Apoios Madeira · Prazos» (`apoios-whatsapp-etalon.png`).

1. **Волна одна на всех** (форма Хаба / Apoios / Cápsula): `M20 80 Q30 74 40 80 Q50 86 60 80 Q70 74 80 80`, толщина 7, круглые концы, поле 100×100.
2. **Буква** своя у каждого проекта: вписана в рамку верх 17 — низ 70 (буква стоит на линии 70), ширина до 60, по центру.
3. **Светлая тема — основная**: плитка rx 22, светлый фон и акцент продукта → `{проект}-icon.svg` (сайты, шапка, фавикон).
4. **Тёмная тема**: фон `#0E1725`, яркий акцент → `{проект}-icon-dark.svg` и аватарка 640 px — для WhatsApp, Telegram, соцсетей и мест, где виден только значок.

## Новый проект
1. Добавить строку в `glyphs.json` (id, имя, буква без волны с цветом `"C"`, светлый фон/акцент, тёмный акцент).
2. `python3 _standards/icons/build.py /tmp/icons` → светлый и тёмный SVG, аватарка 640, PNG 512.
3. `python3 _standards/icons/table.py /tmp/icons` → обновлённая таблица значков.
4. Положить SVG в папку продукта; таблицу и аватарку — в Drive `SeedWave/_standards/Значки…` и в Медиатеку `03 Бренд/Значки…`.

Старые `mark.py` в sono / capsula / piloto главный значок больше не перезаписывают.
